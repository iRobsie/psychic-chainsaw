Game Library Examples

Select a game below to launch it. All games here are written using the modular game library in game-lib or are ports of older demos. To run these examples locally you should serve the project with a local HTTP server.

  • Pong – Single‑player Pong with AI and scaling difficulty
  • Breakout – Classic brick‑breaker with paddle and bouncing ball
  • Snake – Simple implementation of the classic snake game
  • Space Invaders – Shoot down waves of aliens before they reach you
  • Bullet Hell – Dodge endless radial bullet patterns to survive
  • Procedural Snake – Advanced snake game with combos, magnets and AI from the original project
  • Space Trippin – Psychedelic space runner from the original project
  • TinyCraft – Tiny crafting and survival game from the original project

Tip: Use the batch script run_games.bat in the project root to start a local server and open this page automatically on Windows. For GitHub Pages, simply place these files at the root of your repository.
